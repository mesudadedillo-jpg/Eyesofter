# Recursos visuales de EYESOFTER

Esta carpeta contiene los recursos gráficos reutilizables de la aplicación.

- `logo-eyesofter.svg`: logotipo vectorial editable para pantallas, documentación e iconos.
- Las imágenes de Ishihara se conservan en `resources/ishihara/` porque forman parte del material clínico del tamizaje.

Para nuevos recursos use nombres descriptivos y minúsculas, por ejemplo `miniatura-paciente.png` o `icono-camara.svg`.
